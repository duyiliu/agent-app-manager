# Issue 146：Web 工作台入口

> 版本 v2；用户明确要求按更新后的 Issue 实现。设计审查采用 same-context；运行验证与实现审查另行记录。

仅对已登记业务应用发现 `<root>/scenario-test/scenario.config.js`、`index.html` 和项目内 CLI，检查真实路径不越界，不加载项目 JS。使用配置真实路径作为工作台身份，同一配置由多个业务 app 引用时复用。首次点击通过真实 Node 及参数数组启动既有 `serve`，复用登记、锁、日志、身份核验和停止机制；业务进程保持独立。工作台内部登记不进入业务应用列表。

端口由系统分配空闲回环端口，启动时仍检查冲突；只在受管 PID 身份核验通过、该 PID 实际监听选定的 127.0.0.1 端口且 HTTP 可访问时显示运行。竞态、无法核验、进程退出或超时均不冒充可用，更不认领或停止外部服务。跨进程同配置操作使用既有锁；停止仅作用于工作台自身。UI 使用新标签与 noopener，保留可点击 URL。管理台 API 严格验证 app 和操作，写入走 Host、Origin、Sec-Fetch-Site 检查；重操作经 manager 子进程避免阻塞 UI。

不新增 verify、测试任务、报告、代理、工作台嵌入或跨仓修改；自定义路径为 Issue 可选项，暂不实现。工作台 stderr 使用既有日志，展示有界尾部。UI 退出不停止受管工作台。
